# بررسی جمله و نمایش تعداد تکرار کلمات

**توضیح کامل:**
در این بخش کاربر یک جمله را از طریق ورودی دریافت می‌کند.  
ابتدا با استفاده از متد strip، فاصله‌های اضافی از ابتدا و انتهای جمله حذف می‌شود.  
سپس بررسی می‌شود که آیا جمله فقط یک کلمه است یا حاوی فضای خالی (یعنی جمله واقعی).  
در صورت وجود فضای خالی، جمله به لیست کلمات تقسیم می‌شود.  
سپس یک دیکشنری ایجاد می‌شود که در آن هر کلمه به عنوان کلید و تعداد تکرار آن به عنوان مقدار ذخیره می‌شود.  
در نهایت، برای هر کلمه، کلمه و تعداد تکرار آن به صورت مرتب چاپ می‌شود.
